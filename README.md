# 🧑‍💻 DEV-SPACE API - 백엔드

📌 프로젝트 개요  
프로젝트명: DEV-SPACE API (백엔드)  
개발 기간: 2025-08-11 ~ 2025-08-29

🎯 목적  
DEV-SPACE API는 서비스의 핵심 비즈니스 로직과 데이터 관리를 담당하는 백엔드 서버입니다.  
사용자 인증, 게시판 관리, 파일 업로드 등 주요 기능을 REST API로 제공하며, 안정적이고 확장 가능한 구조를 목표로 설계되었습니다.  

주요 목적
- 사용자 인증/인가의 안정성 확보 (JWT & OAuth2)
- 관리자와 일반 사용자 권한 분리
- Naver API 스케쥴링을 통한 개발 정보 내용 제공
- 게시판을 이용한 개발자들의 원활한 소통
- 차트를 이용한 회원 관리

📝 요구사항 정의서 및 기능 명세  

👤 사용자 기능  
- 회원가입 및 로그인 (JWT 발급/재발급)  
- 소셜 로그인 (Google OAuth2)  
- 게시글 작성, 조회, 수정, 삭제
- 댓글 작성, 조회, 수정, 삭제
- 이미지 업로드 및 다운로드
- 내 정보 확인

🧑‍💼 관리자 기능  
- 회원 권한 관리 (ADMIN / USER)  
- 차트를 이용한 이용자 관리
  회원 계정 정지 관리
